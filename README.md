# Donats

Платформа для збору донатів із можливістю створення онлайн-зборів, керування ними та здійснення пожертв через
інтернет-еквайринг.

## Можливості

- Реєстрація та авторизація
- Керування акаунтом
- Створення необмеженої кількості зборів
- Сторінка збору з історією донатів і рейтингом найбільших пожертв
- Донати через LiqPay
- Оновлення до зборів
- Фільтрування за тегами

## Стек

- **Бекенд:** Java 21, Spring Boot
- **Фронтенд:** TypeScript, React
- **База даних:** PostgreSQL
- **Сторонні API:** LiqPay, Cloudinary
